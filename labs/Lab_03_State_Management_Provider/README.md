# Lab 3: State Management with Provider

## Objective
Understand application-wide reactive state management using `ChangeNotifier`, `ChangeNotifierProvider`, and `Consumer` / `context.watch()`.

## Reference Implementations in Project:
- `lib/providers/auth_provider.dart`: User authentication state
- `lib/providers/task_provider.dart`: Task CRUD and filtering
- `lib/providers/settings_provider.dart`: App theme and preferences
