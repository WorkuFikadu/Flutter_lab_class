# Lab 1: My First Flutter App (StatefulWidget & Text Editing)

## Objective
Learn Flutter widget tree basics, `StatelessWidget` vs `StatefulWidget`, `TextEditingController`, and user feedback via `SnackBar`.

## Implementation
Located at: `lib/screens/lab_first_app_screen.dart`

## Key Tests
1. **Name input**: Enter `Worku`, click Submit -> Greeting appears.
2. **Validation**: Click Submit while empty -> Error SnackBar and helper message.
3. **Clear**: Click Clear -> Resets text field and greeting.
